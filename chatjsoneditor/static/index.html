How edits reach Claude

Edits are written to the session's .jsonl immediately, but Claude Desktop does not watch the file — an open conversation keeps its in-memory copy.
  • Best: edit a session that isn't currently open, then open/resume it in Claude.
  • If it's already open, quit and reopen Claude Desktop (the session list re-reads from disk on launch).
  • CLI claude --resume <id> always reads the file fresh.

If a session is being written by Claude while you edit, the save is blocked (409) and you'll see a reload banner.
